# 和十姉妹｜交配予測ラボ（公開試験版）

**羽色・濃淡・斑を、親鳥の外見と任意の祖父母情報から確率的に予測するWebアプリ。**

> 本アプリは、単一飼育集団の繁殖記録から作られた探索的な統計モデルです。DNA解析によって原因変異を同定しておらず、普遍的な遺伝法則、未知血統での予測精度、95%信用区間の実際の被覆率は未検証です。繁殖判断には鳥の健康・福祉を優先してください。

## 公開用パッケージの内容

| ファイル | 内容 |
|---|---|
| `app.py` | Streamlitウェブ画面。父母・祖父母の観察特徴を入力できる |
| `predictor.py` | 外見と任意の祖父母情報から親鳥の潜在遺伝子型の事後確率を計算 |
| `mendel.py` | 常染色体・Z連鎖のメンデル伝達（雄ZZ、雌ZW） |
| `compound.py` | 羽色・濃淡・パイドの階層的な確率予測と区間の計算 |
| `public_model.json` | **匿名集計パラメータのみ**。元ODS/個別血統/個体名は収録しない |
| `export_public_model.py` | 所有者専用の学習済みモデルから匿名集計モデルを再出力するプログラム |
| `MODEL_CARD.md` | 方法論、検証スコア、想定バイアス、出典・倫理面 |
| `tests/test_prediction.py` | 家系推定・遺伝伝達・数値計算の10件の自動テスト |

## ローカル起動

**Python 3.10以降**を利用。フォルダー内で：

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

アプリが開かない場合は、起動ログに示された `http://localhost:8501` をブラウザで開きます。

## 飼育者向けの使い方

1. 父鳥・母鳥の基本色／濃淡／パイドを選択します。わからない場合は「未確認」を維持してください。
2. 親の両親の外見がわかる場合は「祖父母の外見も入力」にチェックを入れます。片側だけ判明していても入力可能です。
3. 子の性別を「指定しない」／「雄」／「雌」から選択します。
4. 「出現確率を計算する」を押すと、子の羽色候補・確率・95%信用区間、父母の遺伝子型の推定分布が表示されます。
5. 詳細表をCSVで保存できます。

**重要な解釈**：例えば「和黒30%（95%信用区間20～40%）」は、仮定したモデルに条件づけた*和黒が生まれる確率自体*の推定です。「和黒が95%保証される」という意味ではありません。

## 誰でも使えるURLで公開する方法

[Streamlit Community Cloud公式デプロイ手順](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy)

1. GitHubで**新規公開リポジトリ**を作ります。
2. **この公開用パッケージの中身だけ**（`app.py`, `public_model.json`, `requirements.txt` 等）をリポジトリ直下にアップロードします。プライベート用ツール・元ODS・`results/model.json`を絶対に追加しないでください。
3. https://share.streamlit.io/ にログインし、`Create app` を選びます。
4. リポジトリ、ブランチ `main`、エントリポイント `app.py` を設定してデプロイします。
5. 発行された `*.streamlit.app` のURLを飼育者に共有します。

これにより他の飼育者はPythonを入れずにブラウザから利用できます。デプロイ・GitHubへの公開操作そのものはパッケージに含まれません。

## 今後のODSの更新

元のODSと個体別学習モデルは**非公開側で管理**してください。配布する「所有者専用・非公開更新ツール」を使います。

1. 元のODSを修正・保存。
2. `python update_and_export.py --ods "/path/to/生体データ_十姉妹.ods" --public-dir "/path/to/public_app"` を実行。
3. `public_app/public_model.json`が匿名集計モデルに更新されるので、そのファイル**だけ**公開GitHubへコミット。
4. 公開版のモデル日付・検証結果が変わったことを確認してから配布。

**注意**：行・列レイアウトを変えると従来のODSパーサが読めなくなる可能性があります。記載・分類法の変更時はモデルと検証を再点検してください。検証未実施の更新結果を旧版の検証成績として提示しないでください。

## プライバシー

- 公開用 `public_model.json` は匿名集計した度数・事前分布・モデル比較結果だけを保持します。**学習元の個別鳥データ・飼育者の個人情報・元ODSは含めません。**
- 集計表中のまれな羽色の組合せから情報の存在を推測できる可能性はあり、厳密な差分プライバシーは保証していません。公開前にモデルファイルの内容をご確認ください。
- アプリコードには入力内容を保存する処理はありません。ただし、Streamlit Community Cloud等に公開した場合、入力内容はその実行サーバーへ送られ、ホスト側の通信ログが残る可能性があります。

## 検証と制約

- 登録785羽、繁殖702羽、121組の単一集団の記録に由来します。
- 40の複合羽色分類の内部ホールドアウト評価（24組、151羽）：多クラスBrier 0.84167 vs 単純出現率0.87577、対数損失2.49984 vs 2.64205、最頻羽色の正解率31.1% vs 34.4%。
- 確率的なスコアは少し改善する一方、単一の羽色を当てる正解率は下回ります。
- **この検証は元集団の「親番号が既知」の予測経路であり、新しいアプリの「外見からの潜在遺伝子型推定」経路は独立に検証されていません。**
- 95%信用区間について頻度論的な被覆率の検証は行っていません。
- 詳細は `MODEL_CARD.md` を参照してください。
